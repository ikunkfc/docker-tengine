# Tengine 便携式打包方案

## 概述

这个方案可以将 RockyLinux 9 构建的 Tengine 打包到一个目录中，让你可以"带着应用到处跑"。

## 使用方法

### 1. 构建并打包

```bash
cd rockylinux/9

# 使用脚本自动打包（推荐）
./package-portable.sh

# 或指定镜像名称和输出目录
./package-portable.sh tengine:rockylinux9 my-tengine-package
```

脚本会自动：
- 检查并构建 Docker 镜像（如果不存在）
- 从容器中提取所有文件
- 创建安装/卸载脚本
- 生成 systemd 服务文件
- 打包成 tar.gz 归档文件
- 计算 SHA256 校验和

### 2. 打包内容

打包后会生成：

```
tengine-portable/                    # 打包目录
├── opt/tengine/                     # Tengine 主目录（包含所有依赖库）
├── usr/sbin/nginx                   # Tengine 可执行文件
├── etc/nginx/                       # 配置文件
├── install.sh                       # 自动安装脚本 ✨
├── uninstall.sh                     # 卸载脚本
├── start-tengine.sh                 # 启动脚本
├── tengine.service                  # systemd 服务文件
├── README.md                        # 英文使用文档
└── package-info.txt                 # 包信息

tengine-rockylinux9-x86_64-YYYYMMDD-HHMMSS.tar.gz      # 压缩包
tengine-rockylinux9-x86_64-YYYYMMDD-HHMMSS.tar.gz.sha256  # 校验和
```

### 3. 传输到目标机器

```bash
# 方式 1: 使用打包好的 tar.gz
scp tengine-rockylinux9-x86_64-*.tar.gz user@target-machine:/tmp/

# 方式 2: 直接复制目录
rsync -av tengine-portable/ user@target-machine:/tmp/tengine-portable/
```

### 4. 在目标机器上安装

#### 方法 A: 使用自动安装脚本（推荐）

```bash
# 解压
tar xzf tengine-rockylinux9-x86_64-*.tar.gz -C tengine-portable

# 进入目录
cd tengine-portable

# 运行安装脚本
sudo ./install.sh
```

安装脚本会自动：
- ✓ 检测操作系统类型
- ✓ 安装运行时依赖（libgd, libxslt, libxml2, libmaxminddb）
- ✓ 复制文件到系统目录
- ✓ 创建 nginx 用户
- ✓ 设置正确的权限
- ✓ 验证安装

#### 方法 B: 安装到自定义目录

```bash
sudo ./install.sh /opt/custom-location
```

#### 方法 C: 手动安装

```bash
# 1. 安装依赖
# RHEL/Rocky/Fedora/CentOS
sudo dnf install -y gd libxslt libxml2 libmaxminddb

# Ubuntu/Debian
sudo apt-get install -y libgd3 libxslt1.1 libxml2 libmaxminddb0

# 2. 复制文件
sudo cp -r opt/tengine /opt/
sudo cp usr/sbin/nginx /usr/sbin/
sudo cp -r etc/nginx /etc/

# 3. 创建用户
sudo groupadd -r nginx
sudo useradd -r -g nginx -s /sbin/nologin -d /var/lib/nginx nginx

# 4. 创建目录
sudo mkdir -p /var/lib/nginx /var/log/nginx
sudo chown -R nginx:nginx /var/lib/nginx /var/log/nginx

# 5. 测试
/usr/sbin/nginx -t
```

### 5. 运行 Tengine

#### 直接运行（前台）

```bash
./start-tengine.sh
```

#### 后台运行

```bash
/usr/sbin/nginx
```

#### 使用 systemd（推荐）

```bash
# 安装服务
sudo cp tengine.service /etc/systemd/system/
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start tengine

# 设置开机启动
sudo systemctl enable tengine

# 查看状态
sudo systemctl status tengine
```

### 6. 管理命令

```bash
# 测试配置
/usr/sbin/nginx -t

# 重新加载配置
/usr/sbin/nginx -s reload

# 停止服务
/usr/sbin/nginx -s stop

# 优雅停止
/usr/sbin/nginx -s quit

# 重新打开日志文件
/usr/sbin/nginx -s reopen

# 查看版本
/usr/sbin/nginx -V
```

## 兼容性

- RockyLinux 8/9

- RHEL 8/9

- Fedora 35+
- Ubuntu 22.04+
- Debian 11+
- 其他使用 glibc 2.34+ 的 x86_64 Linux 发行版

### ❌ 不兼容的系统

- Alpine Linux（使用 musl libc）
- 非常老的发行版（glibc < 2.34）
- 非 x86_64 架构（ARM、RISC-V 等需要重新编译）

### 检查兼容性

```bash
# 检查 glibc 版本（需要 2.34+）
ldd --version

# 检查架构（需要 x86_64）
uname -m

# 检查依赖库
ldd /usr/sbin/nginx
```

## 工作原理

### RPATH 技术

这个打包方案使用 **RPATH** 技术实现"半静态链接"：

1. **自包含的库**（通过 RPATH）：
   - LuaJIT
   - Tongsuo (GMSSL)
   - PCRE2
   - zlib
   - Brotli
   - GeoIP

   这些库都编译到 `/opt/tengine/` 目录下，通过 RPATH 自动查找。

2. **系统库**（动态链接）：
   - glibc（必须，Linux 系统核心库）
   - libgd（图像处理）
   - libxslt（XSLT 支持）
   - libxml2（XML 支持）
   - libmaxminddb（GeoIP2 支持）

   这些库需要在目标系统上安装。

### 为什么不能完全静态链接？

1. **glibc 限制**：glibc 不适合静态链接，某些功能（如 DNS 解析）依赖动态加载
2. **LuaJIT 要求**：LuaJIT 和 Lua C 模块必须动态链接才能正常工作
3. **Nginx 模块架构**：许多第三方模块设计为动态链接

但通过 RPATH，我们已经实现了 **90% 的依赖自包含**，只需要 4 个小的系统库！

## 目录结构

```
/opt/tengine/              # Tengine 主目录（所有自定义编译的库）
  ├── lualib/              # Lua 库文件
  ├── luamod/              # Lua C 模块（cjson.so）
  ├── luajit/              # LuaJIT 安装
  │   ├── bin/
  │   ├── lib/             # RPATH: libluajit-5.1.so
  │   └── share/
  ├── Tongsuo/             # 国密 SSL 库
  │   ├── bin/
  │   └── lib64/           # RPATH: libssl.so, libcrypto.so
  ├── pcre2/               # PCRE2 正则库
  │   ├── bin/
  │   └── lib/             # RPATH: libpcre2-8.so
  ├── zlib/                # zlib 压缩库
  │   └── lib/             # RPATH: libz.so
  ├── geoip/               # GeoIP 库
  │   ├── bin/
  │   └── lib/             # RPATH: libGeoIP.so
  └── brotli/              # Brotli 压缩库
      └── lib/             # RPATH: libbrotli*.so

/etc/nginx/                # 配置文件
  ├── nginx.conf           # 主配置
  ├── conf.d/              # 虚拟主机配置
  │   ├── default.conf
  │   └── vhost.gmssl.conf
  └── ssl/                 # SSL 证书

/usr/sbin/nginx            # Tengine 可执行文件（包含 RPATH）
/var/lib/nginx/            # 临时文件目录
/var/log/nginx/            # 日志目录
```

## 常见问题

### 1. 提示 "error while loading shared libraries"

说明缺少运行时依赖，安装即可：

```bash
# RHEL/Rocky/Fedora
sudo dnf install -y gd libxslt libxml2 libmaxminddb

# Ubuntu/Debian
sudo apt-get install -y libgd3 libxslt1.1 libxml2 libmaxminddb0
```

### 2. 如何查看需要哪些库？

```bash
ldd /usr/sbin/nginx
```

所有位于 `/opt/tengine/` 下的库都应该能找到，只有系统库会显示在 `/lib` 或 `/usr/lib` 下。

### 3. 可以在 Ubuntu 上运行吗？

可以！只要：
- glibc 版本 >= 2.34
- 安装了 4 个运行时依赖库

Ubuntu 22.04+ 完全兼容。

### 4. 可以同时在多台机器上部署吗？

可以！这就是便携式打包的优势：
1. 一次构建
2. 打包成 tar.gz
3. 分发到多台机器
4. 在每台机器上运行 `./install.sh`

### 5. 如何卸载？

```bash
sudo ./uninstall.sh
```

### 6. 占用多少空间？

- 打包目录：约 150-200 MB
- tar.gz 归档：约 50-80 MB（压缩后）

/usr/sbin/nginx -s reload

```bash

/usr/sbin/nginx -V

echo $LUA_PATH

# 查看 RPATH
readelf -d /usr/sbin/nginx | grep RPATH
```
